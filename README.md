# 世界の企業時価総額ランキングをExcelに出力

[CompaniesMarketCap](https://companiesmarketcap.com/)から世界の企業時価総額ランキングを取得し、次の3シートを持つExcelファイルを作成するPythonプログラムです。

| シート | 内容 |
| --- | --- |
| 世界1～20位 | 世界ランキング上位20社 |
| 世界100位以内_日本企業 | 世界ランキング1～100位に入る日本企業 |
| 世界101～200位_日本企業 | 世界ランキング101～200位に入る日本企業 |

各シートには、世界順位、企業名、時価総額（米ドル）、時価総額（十億米ドル）、国名を記載します。企業名はサイトの表記を使用します。日本企業の件数や順位は実行時点によって変わります。

以下では、Windowsでの使い方を説明します。インターネット接続が必要です。

## 1. Pythonをインストールする

1. [Python公式サイトのWindows用ダウンロードページ](https://www.python.org/downloads/windows/)を開きます。
2. Python 3.10以降の、通常のWindows用インストーラーをダウンロードします。一般的なWindowsパソコンでは64ビット版を選びます。
3. インストーラーを起動します。最初の画面に **Add python.exe to PATH** がある場合はチェックします。
4. **Install Now** をクリックし、インストールを完了します。

すでにPython 3.10以降が入っている場合は、再インストールは不要です。

Windowsのスタートメニューで「cmd」と検索し、**コマンドプロンプト**を開きます。次のコマンドでインストールを確認します。

```bat
py --version
```

`Python 3.13.3` のようにバージョンが表示されれば準備完了です。`py` が使えない場合は、次を試してください。

```bat
python --version
```

`python` で確認できた場合は、以降のコマンドの `py` を `python` に置き換えてください。複数のPythonが入っている場合は、確認したPython 3.10以降を使います。

## 2. プログラムをダウンロードする

このリポジトリの **Code → Download ZIP** をクリックし、ダウンロードしたZIPファイルを右クリックして **すべて展開** を選びます。

展開したフォルダの中に、次のファイルがあることを確認してください。

```text
companies_marketcap_to_excel.py
```

## 3. 必要なライブラリをインストールする

**コマンドプロンプト**で、次のコマンドを実行します。Pythonの `>>>` が表示される画面やIDLEのShellには入力しません。

```bat
py -m pip install requests beautifulsoup4 openpyxl
```

| ライブラリ | 用途 |
| --- | --- |
| requests | Webページの取得 |
| beautifulsoup4 | HTMLから企業情報を抽出 |
| openpyxl | Excelファイルの作成と書式設定 |

ライブラリのインストールは通常、最初の1回だけで十分です。

## 4. プログラムを実行する

### コマンドプロンプトから実行する

1. エクスプローラーで、`companies_marketcap_to_excel.py` が入っているフォルダを開きます。
2. エクスプローラー上部のアドレスバーに `cmd` と入力してEnterキーを押します。そのフォルダを作業場所とするコマンドプロンプトが開きます。
3. 次のコマンドを実行します。

```bat
py companies_marketcap_to_excel.py
```

実行すると、世界ランキングの1ページ目と2ページ目を取得します。取得・保存に成功すると、各シートの企業数と、Excelファイルの保存場所が表示されます。

### IDLEから実行する

1. スタートメニューから **IDLE** を開きます。
2. **File → Open** から `companies_marketcap_to_excel.py` を開きます。
3. プログラムの編集画面で **F5** を押します。メニューの **Run → Run Module** でも実行できます。
4. IDLEのShellに処理結果と保存場所が表示されます。

## 5. 作成されたExcelを確認する

通常は、プログラムと同じフォルダに、実行時の日本時間を含むファイル名で保存されます。

```text
企業時価総額_YYYYMMDD_HHMMSS.xlsx
```

ファイルをExcelで開き、3つのシートを確認してください。

保存先やファイル名を指定する場合は、コマンドプロンプトで次のように実行します。

```bat
py companies_marketcap_to_excel.py --output ranking.xlsx
```

この場合は、コマンドプロンプトの現在のフォルダに `ranking.xlsx` が保存されます。同名のファイルがある場合は上書きされます。

絶対パスも指定できます。パスに空白が含まれる場合に備え、ダブルクォーテーションで囲みます。

```bat
py companies_marketcap_to_excel.py --output "C:\Users\ユーザー名\Desktop\ranking.xlsx"
```

`ユーザー名` は、ご自身のWindowsユーザー名に置き換えてください。デスクトップをOneDriveで管理している場合は、実際の保存先に合わせてパスを変更します。

## エラーが出た場合

| 表示・症状 | 対処方法 |
| --- | --- |
| `py` が認識されない | `python --version` を試します。どちらも使えない場合はPythonのインストールを確認し、コマンドプロンプトを開き直します。 |
| `ModuleNotFoundError` | 「3. 必要なライブラリをインストールする」のコマンドを、実行に使うPythonで実行します。 |
| `can't open file` | プログラムが入っているフォルダで実行しているか、ファイル名が正しいかを確認します。 |
| Excelを保存できない | 同名のExcelを閉じ、書き込み可能なフォルダを指定して再実行します。 |
| ランキング表が見つからない／100件が揃わない | サイトのアクセス制限やHTML構造の変更が考えられます。時間を置いて再実行し、続く場合はプログラムの修正が必要です。 |
| 通信エラー | インターネット接続を確認し、時間を置いて再実行します。 |

## データについて

- 順位は日本国内順位ではなく、サイト掲載の**世界順位**です。
- 時価総額はサイトの表示値を数値に変換しています。元の表示値が丸められているため、厳密な未丸め値ではありません。
- `T` は1兆米ドル、`B` は10億米ドルです。Excelの「十億米ドル」列では単位を統一しています。
- 実行するたびにページを取得します。作成済みのExcelは自動更新されません。
- 2ページは順に取得するため、完全に同一時刻の値ではありません。
- 各ページで100順位が揃ったことを確認し、取得に失敗した場合は新しいExcelを保存しません。
- 取得元サイトの利用条件を確認し、短時間の連続実行は控えてください。
